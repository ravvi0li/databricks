US Emissions Dashboard | Databricks

# Overview
A personal data visualisation project exploring emissions patterns across the continental United States using Databricks.

I built this project to gain hands-on experience with Databricks and explore how data visualisations can make environmental data easier to understand.

# Dashboard Features
- **Geographic distribution:** Map showing emissions data across the continental US.
- **Emissions vs. population:** Scatter plot exploring the relationship between population and emissions per person.
- **State-level breakdown:** Visualisation of the emissions contribution of leading states.
- **County comparison:** Bar chart comparing total emissions across counties.
